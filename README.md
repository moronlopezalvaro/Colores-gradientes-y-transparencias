# Colores, gradientes y transparencias 🌈
A partir de la imagen proporcionada, deberéis recrear visualmente las diferentes tarjetas.

La página deberá mostrar un título y un conjunto de tarjetas con diferentes estos estilos de color y gradientes.

# Usar:
header para el título
main para el contenido
section o div para el contenedor de tarjetas

Cada tarjeta debe ser un elemento independiente.

# Cada tarjeta debe cumplir lo siguiente:
Bordes redondeados (border-radius)
Texto centrado vertical y horizontalmente
Tipografía legible
Espaciado entre tarjetas
Fondo general con un gradiente suave
